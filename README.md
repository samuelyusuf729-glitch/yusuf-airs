Yusuf Air ✈️ | Fly High, Fly Smart

Yusuf Air is a modern, responsive, and feature-rich airline ticket booking web application. It provides users with a seamless platform to search for global flights, view dynamic live pricing, select preferred partner airlines, and complete secure reservations with automated e-ticket confirmations.

🌟 Features

Interactive Multi-Step Booking Flow: Search flights by origin, destination, trip type, and passenger count.

Dynamic Flight Results: Explore available flights from top global partner airlines (Emirates, Qatar Airways, Singapore Airlines, British Airways).

Secure Payment Modal: Simulated payment checkout with validation for booking summaries and fare calculations.

Instant E-Ticket Generation: Automatically generates a unique booking reference code (#YA-XXXXX) upon successful payment completion.

Responsive Design: Fully optimized layout for desktop, tablet, and mobile screens using modern CSS and Flexbox/Grid architectures.

🛠️ Tech Stack

HTML5: Semantic document structure and accessibility markup.

CSS3: Custom properties (CSS variables), modern Flexbox/Grid layouts, and responsive styling.

JavaScript (ES6+): Dynamic DOM manipulation, state management, modal handlers, and event listeners.

FontAwesome: Professional icons for aviation, time, checkout, and security indicators.

🚀 Getting Started

To run the Yusuf Air web application locally on your machine, follow these simple steps:

Clone or Download this repository containing your project files.

Ensure you have a single project directory containing your integrated files, or separate index.html, style.css, and script.js files linked properly.

Open index.html in any modern web browser (Google Chrome, Mozilla Firefox, Safari, Microsoft Edge).
